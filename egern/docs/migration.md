# 从 Go 版 CDT-Monitor 迁移

本文说明如何从自建 Go 后端迁移到 Egern 独立插件，以及两者并存时的注意点。

## 1. 选择模式

| 你的情况 | 建议 |
| --- | --- |
| 只想要手机上看流量与状态，能接受手机端执行 | **直连模式**（`cdt-monitor.yaml`） |
| 已运行 Go 服务，希望复用它的调度、历史与凭据保管 | **服务器模式**（`cdt-monitor-server.yaml`） |
| 需要**不依赖手机状态**的自动停机、准确计划、持续保活 | 继续由 Go 后端执行；Egern 侧只做展示 |

Egern 的定时脚本是「脚本实际获得执行机会时运行」。iOS 在后台、锁屏、低电量或强退后
**不保证**按时唤醒，因此手机端**不适合**承担必须准时或必须执行的停机。

## 2. 直连模式迁移步骤

1. 在 RAM 中创建只读用户（CDT 查询，可选 ECS 查询 / BSS 查询）；
2. 安装 `cdt-monitor.yaml`，填入 `CDT_ACCESS_KEY_ID` / `CDT_ACCESS_KEY_SECRET`；
3. **手工重新确认额度**：Go 版的 `max_traffic` 表示「本周期上限」，请填入 `CDT_QUOTA`
   并选择正确的 `CDT_QUOTA_UNIT`；
4. 若要显示实例状态，填 `CDT_INSTANCE_ID`；
5. 打开 Analytics 预览，核对流量范围与单位。

### ⚠️ 单位必须重新确认

Go 版把接口返回值除以 1024³（GiB）却标成 **GB**，两者相差约 **7.4%**。
这意味着：

- 旧配置里的 `max_traffic = 200` 如果被理解为「200 GB」，实际边界并不等于 200 GB；
- 迁移时**必须显式选择**单位，本插件不会替你猜。

如果你希望沿用旧数字的口径，选择 `GiB`；如果按阿里云权益的 GB 口径重新定义，
选择 `GB` 并接受停机边界随之改变。**本插件不会无提示地改变你的停机边界。**

### ⚠️ 历史不会被继承

Go 版的小时/日表存的是**接口累计值采样**，且当前 provider 没有周期参数。
直连模式**从安装后开始采样**，不会导入旧的 30 天历史，也不会声称已继承。

### 关于「本月」

`ListCdtInternetTraffic` 没有任何时间范围参数，官方也未说明重置时点。
因此本插件把该 scope 标为「接口累计（统计周期待确认）」，
**不会**把数字当作「本月累计」，也**不会**在手机端月初时擅自重置。

## 3. 服务器模式迁移步骤

1. 在 Go 服务端「设置 → API Key」创建 **只读** Key（scope = `widget:read`）；
2. 安装 `cdt-monitor-server.yaml`，填 `CDT_BASE_URL` 与 `CDT_READ_TOKEN`；
3. 无需在手机上配置任何云凭据。

### v1 数据的新鲜度限制（重要）

Go v1 接口的 `updated_at` / `last_updated`：

- 在**监控任务入队**时写入；
- 也会被控制动作刷新；
- 状态查询失败时还可能随成功的流量查询一起被更新。

因此它**不是**云端采样时间。本插件的处理：

- 该值只作为 `legacyUpdatedAt` 保存，界面显示「服务器记录更新于…」并标注可能陈旧；
- `trafficObservedAt` / `statusObservedAt` **保持未知**；
- 该数据**在代码层面被禁止**作为本地自动控制的新鲜度依据。

### 行与账号的对应关系

v1 摘要是**按配置行**而不是按账号范围组织的。仅凭脱敏的 AK 无法判断两行是否同一账号，因此：

- 服务器模式**逐行展示**，不把未知范围的用量/额度/余额相加；
- 需要合计时，请在高级配置里用显式 `accountId` 分组。

### 服务端 v2（尚未实现）

若要更精确的字段级新鲜度，需要为后端新增兼容字段或新版本接口
（`accountUid` / `scopeId` / `unit` / `period` / `trafficObservedAt` / `statusObservedAt`），
同时保留 v1 以免破坏 Web 与 Android 客户端。**本次迁移未修改任何 Go 代码。**

## 4. 不改动的部分

- Go 服务、React Web、Android 原型、Docker 与既有发布流程**均未修改**；
- 原有 API 路由与鉴权语义不变；
- MIT 许可证与原作者署名保留。

## 5. 权限对照

| 用途 | 需要的最小权限 |
| --- | --- |
| 只读监控（直连） | CDT 查询；可选 ECS 实例状态查询 |
| 可选账单 | BSS 余额与实例账单查询 |
| 控制（默认关闭） | 仅显式实例的 StartInstance / StopInstance |
| 只读监控（服务器模式） | 服务端 API Key 的 `widget:read`，**不需要** `instance:control` 或 `admin` |

**不要**使用 `AdministratorAccess`，也**不要**把 `instance:control` Key 放进小组件。

## 6. 回退

1. 在 Egern 中禁用或删除对应模块；
2. 如需清理本地缓存，删除 Egern 中该模块的 Env 或重装模块；
3. Go 服务与数据目录不受影响，可继续使用原控制台。

## 7. 迁移检查清单

- [ ] 只读 RAM 凭据已创建，且未使用主账号
- [ ] `CDT_QUOTA` 与 `CDT_QUOTA_UNIT` 已按自己的计费口径**重新确认**
- [ ] 已核对小组件显示的流量范围（国内 / 海外）与地域分类
- [ ] 已知悉「接口累计（统计周期待确认）」的含义
- [ ] 服务器模式下已知悉 v1 时间戳不可作为云采样时间
- [ ] 已确认本地控制处于关闭状态（除非已完成真机验证）
- [ ] 分享配置/截图前已移除 Env 中的凭据
